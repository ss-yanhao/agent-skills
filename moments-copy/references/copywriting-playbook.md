# 朋友圈文案手册

> 只写能直接用的东西：规格、角度、套路、黑名单。不写理论。
> ⚠️ 与 `user/style-profile.md`（你自己的风格）冲突时，**以你的风格为准**。
> 本手册是通用默认，你的手感优先。

---

## 一、折叠规则（硬约束）

### 什么时候折叠

| 情况 | 显示结果 |
|---|---|
| **≤ 6 行** | 全部显示，**不折叠** ✅ |
| > 6 行，手动输入，< 200 字 | 显示前 6 行 + 蓝色「全文」 |
| **复制粘贴 > 200 字** | **整段压成一行 + 灰底** ❌ 最糟 |
| 评论 > 100 字 | 评论被折叠 |

> 微信官方口径：这是「原创保护」，鼓励即兴原创、抑制搬运。

### emoji 吃字数

**1 个 emoji ≈ 4 个字符。** 15 个 emoji = 吃掉 60 字符，等于少写 60 个汉字。

**数量**：默认**每行末尾 1 个**（清爽且省预算）。
行首的 `✅` 这类标记除外——它是排版符号，不算装饰 emoji。
你自己的习惯写在 `user/style-profile.md` 里，以那个为准。

### 字数预算（含 emoji×4 + 标点）

| 版本 | 行数 | 字符预算 |
|---|---|---|
| 短促版 | 3-4 行 | ≤ 110 |
| 场景版 | 5-6 行 | ≤ 170 |
| 卖点版 | 6 行 | ≤ 200 |
| **绝对红线** | — | **> 200 必单行折叠** |

**算法**：汉字数 + emoji 数 × 4 + 标点数 ≤ 预算。写完自己数一遍，超标就砍。

### 防折叠发布法（复制粘贴时必做）

1. **首字母法**（最稳）：输入框先打个 `A` → 粘贴全文到 A 后面 → 删掉 A → 发布
2. **分段粘贴法**：每次粘 < 200 字，分多次粘，段间手动换行
3. **记事本中转**：先粘备忘录清掉隐形格式，再复制到朋友圈
4. **首尾删减法**：粘贴后删掉首字和末字，再手动补回来
5. **手动换行**：每 30-50 字手点一次换行，**别用输入法自动换行**（自动换行的隐形空格仍会被识别）

⚠️ **营销号标记**：高频发广告/重复文案的账号会被系统打标，
之后**无论手动还是粘贴都强制单行折叠**。一天最多一条，别连发雷同内容。

### 其他规格

| 项目 | 数值 |
|---|---|
| 配图数 | 1 / 3 / 4 / 6 / 9 张最好看（2、5、7、8 张留空位难看） |
| 话题标签 | 1-2 个即可，多了像微商 |
| 首屏可见 | 前 2 行，钩子必须放这 |

## 二、三类场景骨架

### A. 门店活动 / 开业
```
[痛点或反问开场] + [到店理由一个] + [时间紧迫感] + 【产品/品牌】+ 📍地址
```
- 地点锚点具体到**商圈/街道**：「<城市><商圈>」比只写城市有用
- 到店理由只给一个最强的
- 紧迫感用真实时间/数量，不用「抓紧」「速来」

### B. 产品种草
```
[一个具体场景] + [一个细节/数字] + [轻引导] + 【产品】
```
- 场景具体到「谁、在哪、什么时候」
- 细节只挑一个
- 轻引导：不说「买」，说「可以去看看」「到店能试」

### C. 品牌宣传
```
[一句能被记住的话] + [一个具体事实支撑] + [留白]
```
- 目标是被记住，不是转化
- 支撑事实必须具体（年份、人数、地点）

## 三、角度矩阵（12 个切入点，三版选三个不同族的）

多样性的根在这。**同一族的角度不能用在两版上。**

| 族 | 角度 | 首行长什么样 |
|---|---|---|
| **痛点族** | ① 痛点直击 | `<用户真实的难受，用大白话>` |
| | ② 反问连击 | 「你是否经历过…？你是否觉得…？」 |
| | ③ 代价恐吓 | `<一直拖着不管，会怎样>` ❌ |
| **场景族** | ④ 具体的人 | `<某类人> 的一天，从…开始` |
| | ⑤ 时间切片 | `<某个具体时刻>，<状态>` |
| | ⑥ 身份标签 | 「别让`<标签>`成为你的标签」 |
| **认知族** | ⑦ 反常识 | 「该换思路了👇」/「不是 X，是 Y」 |
| | ⑧ 对比反差 | `<一个坏的日常>` + `<你的产品>`，句式对称 |
| | ⑨ 悬念留白 | `<做了一件事>`，先不说是什么 |
| **信息族** | ⑩ 数字罗列 | `<数字>+<卖点>` 打头 |
| | ⑪ 倒计时紧迫 | `<N 天> 抢回/搞定 <什么>` |
| | ⑫ 权威/溯源 | `<认证/产地/工艺>`：从哪来到哪去 |

**选法**：短促版从「痛点族」或「认知族」挑（冲击力），
场景版从「场景族」挑（有人有画面），卖点版从「信息族」挑（有料）。跨族选，必然不重样。

## 四、三版骨架

| 版本 | 行数 | 字符预算 | 人称 | 默认角度族 |
|---|---|---|---|---|
| **短促版** | 3-4 行 | ≤ 110 | 无人称 / 第二人称 | 痛点族 / 认知族 |
| **场景版** | 5-6 行 | ≤ 170 | 第一人称 / 具体的人 | 场景族 |
| **卖点版** | 6 行 | ≤ 200 | 无人称列点 | 信息族 |

⚠️ **三版都必须 ≤ 6 行**（超过就折叠，前面白写）。
区分三版靠**信息密度和角度**，不是靠长度——别为了显得有料而写长。

**每版只打一个卖点。** 三个卖点分给三版，比每版塞三个强。

## 五、首行钩子的六种写法

| 写法 | 公式 | 例子方向 |
|---|---|---|
| 反常识 | 「不是 X，是 Y」 | 不是打折，是… |
| 数字 | 具体数字开头 | `<年数>`，第一次… |
| 场景代入 | 一句对白或画面 | 「妈，这个不甜」 |
| 悬念 | 说一半 | 开业前，先做了一件事 |
| 地点锚点 | 地名 + 短句 | `<城市>`，明天见 |
| 身份标签 | 点名人群 | `<某类人>`，看一眼 |

**检验方法**：把首行单独拿出来看，如果不能让人停下来，重写。

## 六、趣味性六招（至少命中一招，否则重写）

1. **意外**：说一个反直觉的事实或转折
2. **具体**：用细节代替形容词（「蹲下起身要扶墙」胜过「关节不适」）
3. **人话**：写一句像真人说的（句式对称的对比最出金句）
4. **画面**：给一个能看见的场景（「温水一冲，5 秒搞定」）
5. **节奏**：短句连击、排比三连、重复词
6. **玩梗**：适度的网感词（过气梗别用）

### 陈词滥调黑名单（用了就废）

**开业/活动类**：盛大开业、震撼来袭、不见不散、欢迎莅临、恭候光临、
惊喜不断、好礼送不停、不容错过、精彩纷呈、诚邀您

**产品/品牌类**：品质之选、匠心打造、臻品、尊享、非凡体验、
一如既往、值得信赖、首选品牌、为您保驾护航

**结尾类**：快来抢购吧、千万不要错过、赶紧行动起来、你值得拥有

> 这些词的问题不是「错」，是**没信息量**。换成具体事实或一句人话。

## 七、联网取势（借当下的势）

**顺序**：先 `date` 拿准确日期 → 再搜节气/节日/热点 → 最后搜同行。

| 借什么 | 怎么搜 | 安全性 |
|---|---|---|
| 节气 | `<当前月份> 节气` | ⭐⭐⭐ 最安全，和食品/健康天然贴合 |
| 节日 | `<当前月份> 节日 营销` | ⭐⭐ 沾得上才用 |
| 热点 | `最近热点 <领域>`（freshness d7） | ⭐ 容易翻车，慎用 |
| 同行写法 | `<品类> 朋友圈文案` | 只偷结构不偷词 |

**筛选原则**：
- **沾得上才用**，硬蹭比不蹭更尴尬
- **一版只借一个势**，三版借三个不同的
- 节气 > 节日 > 热点

## 八、5 条硬底线（朋友圈场景，只守这五条）

不做全面法规扫描，只拦真正会出事的：

1. **不写医疗功效承诺** —— 治疗 / 治愈 / 抗癌 / 降血糖（食品保健品尤其不能碰）
2. **不编数据** —— 含量、销量、人数、折扣，没有就不写
3. **不搞虚假紧迫感** ——「最后一天」「仅剩 X 席」必须是真的
4. **不伪造权威** ——「国家认证」「专家推荐」，无授权不写
5. **不贬低竞品** —— 不点名、不暗讽

> 极限词（最 / 第一 / 顶级）**不处理**——朋友圈要传播力，不要报批口径。
> 除非用户说这条要同步到公众号或正式物料。

## 十、常见翻车点

1. **写了却折叠了** —— 超 6 行或超 200 字符，回去看第一章的预算表
2. **三版长得像** —— 角度没跨族，回去看第三章
3. **文案和海报主标题重复** —— 海报写了「盛大开业」，文案就从侧面切
4. **一条塞太多信息** —— 一条只完成一个任务
5. **没有动词** —— 结尾全是名词堆砌，读者不知道要干嘛
6. **抄同行整句** —— 结构可以学，句子必须自己写
7. **emoji 超预算** —— 15 个 emoji = 60 字符，数着用
